# AURA CLOUD — Free Website Starter

A responsive static Minecraft hosting website concept in a black/purple theme.

## Pages
- `index.html` — landing page
- `plans.html` — sample INR pricing
- `login.html` — demo-only login form
- `dashboard.html` — static customer dashboard preview
- `support.html` — support information

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository named `aura-cloud`.
3. Upload all files and folders from this ZIP (keep `assets/` folder).
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose `main` and `/ (root)`, then Save.
7. Wait for the published URL shown in the Pages section.

## Important limitations
This is a static frontend preview. It does NOT provide real authentication, billing, payments, ticket storage, server provisioning, console access, or Pterodactyl integration. Do not collect customer passwords or payments through this demo. The displayed prices and specifications are placeholders; confirm real server capacity and final prices before launch.

When ready, install Pterodactyl Panel and Wings on a VPS, then integrate the client area using a secure backend or supported billing/client portal. Never expose Pterodactyl application keys in browser JavaScript.
